# 打包

## 打包jar

```bat
// 1. 切换到 JDK 17+（把路径改成你自己的）
set JAVA_HOME=C:\jdk-17
set PATH=%JAVA_HOME%\bin;%PATH% 
gradlew :desktop:dist --console=plain
```

## 打包exe

```bat
C:\Users\a\.jdks\ms-17.0.20.1\bin\jpackage.exe
     --type app-image `
     --name Muyu `
     --app-version 1.0 `
     --input 'D:\java\desktopwallpaper\desktop\build\libs' `
     --main-jar desktop-1.0.jar `
     --main-class wk.com.test.MuyuLauncher `
     --dest 'D:\java\desktopwallpaper\desktop\build\muyu-package'
```

### type指定打包类型

常见类型：

|类型|作用|
|---|---|
|app-image|生成独立应用目录|
|exe|生成 Windows 安装程序|
|msi|生成 Windows Installer 安装包|

这里选择 app-image，不会生成安装向导，而是生成一个可以直接运行的应用目录。

### 应用名称

```bat
--name Muyu
```

### 应用版本

```bat
--app-version 1.0
```

### 指定 JAR 文件所在目录

```bat
--input 'D:\java\desktopwallpaper\desktop\build\libs'
```

告诉 jpackage：需要打包的 JAR 文件及其依赖文件存放在哪里。

### 指定主 JAR

```bat
--main-jar desktop-1.0.jar
```

### 指定主类

```bat
--main-class wk.com.test.MuyuLauncher
```

### 指定输出目录

```bat
--dest 'D:\java\desktopwallpaper\desktop\build\muyu-package'
```

## 指定打包结果保存的位置

```bat
--dest 'D:\java\desktopwallpaper\desktop\build\muyu-package'
```
