# desktop壁纸显示

desktop显示包括静态和动态壁纸

## 统一壁纸控制器

双击 `bat/wallpaper-manager.bat` 打开现有壁纸列表，统一预览、切换、打开设置或停止壁纸。使用和接入方法见 [统一壁纸控制器](doc/WALLPAPER_MANAGER.md)。

## 四季节气壁纸

新增随二十四节气、实时天气和昼夜变化的树木倒影壁纸。双击 `bat/seasons.bat` 启动，使用方法见 [四季节气壁纸](doc/SEASONS_WALLPAPER.md)。
